# בדיקת אבטחה ופרטיות: Obscura 1.3.1

היקף הבדיקה:
- המניפסט ורכיבים חשופים.
- הרשאות.
- נתונים שנכנסים מאפליקציות אחרות.
- קבצים ופרטיות.
- סודות ב-git (כל ההיסטוריה).
- APIs מסוכנים.
- תלויות.
- ה-APK החתום.

## ממצאים שתוקנו

| חומרה | ממצא | תיקון |
|---|---|---|
| בינונית | **Confused deputy בעריכה חיצונית:** "ערוך ב-Obscura" (ACTION_EDIT) קיבל כל URI, כולל `file://`. אפליקציה זדונית יכלה לגרום ל-Obscura לפתוח קובץ פרטי שלה, וכשהמשתמש שומר, להעתיק אותו לגלריה הציבורית. | `IncomingImage`: מתקבל רק `content://` של ספק של אפליקציה אחרת, מסוג `image/*`. עם 4 בדיקות יחידה. |
| נמוכה | תמונה חיצונית ענקית (למשל 200MP) הייתה ממלאת את הזיכרון בשמירה מהסטודיו. | תקרה של 8192 פיקסלים בצד הארוך. התמונות של Obscura (8160) לא מושפעות. |

## נבדק ותקין

| תחום | מצב |
|---|---|
| הרשאות | `CAMERA` בלבד. **אין `INTERNET`**, כך שהאפליקציה לא יכולה לשלוח נתונים לשום מקום. |
| רכיבים חשופים | `MainActivity` בלבד: מסך הפתיחה, `STILL_IMAGE_CAMERA`, `EDIT` (מוגן עכשיו). אין services, receivers או providers. |
| גיבוי | `allowBackup=false`. |
| Build | ‏Release עם R8 (minify + shrink), לא debuggable, חתום. |
| סודות | מפתח החתימה וקובץ הסיסמאות מעולם לא נכנסו ל-git (נבדקה כל ההיסטוריה). הם ב-.gitignore. |
| קוד מסוכן | אין `exec`, טעינת קוד דינמית, WebView, JavaScript bridge, sockets, ‏PendingIntent או broadcasts. |
| תלויות | ספריות runtime של androidx (Google) בלבד. Paparazzi ו-JUnit לבדיקות בלבד. |
| קבצים | נכתבים רק דרך MediaStore לתיקיות של האפליקציה (`DCIM/Obscura`, `Download/Obscura`), בלי הרשאת אחסון רחבה. הגלריה קוראת רק את התמונות של האפליקציה. |
| שיתוף | הרשאת קריאה זמנית לתמונה אחת, רק לאפליקציה שנבחרה. |
| מיקום | האפליקציה לא מבקשת מיקום. ‏EXIF של GPS מועתק רק אם קיים ב-JPEG של המצלמה, וללא הרשאת מיקום אין כזה. |
| לוגים | אין ב-Log כתובות, נתיבים או מידע אישי. |

## לשים לב (לא באג)
- **הקלטת אבחון** (כבויה כברירת מחדל): קובץ ה-zip ב-`Download/Obscura` מכיל:
  - את הפריימים שצולמו, כלומר את מה שהיה מול המצלמה, למשל אנשים;
  - את דגם המכשיר;
  - את כל נתוני המצלמה.
  כדאי לשתף אותו רק עם מי שמנתח אותו.
- **ייצוא JSON** של דוח החיישן: מידע על המכשיר והמצלמות בלבד.
